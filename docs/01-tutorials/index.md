# Tutorials

Learning-oriented labs introduce the scripts safely in an isolated temporary directory without modifying a live MariaDB instance.

- [Backup Discovery and Log Rotation Lab](01-backup-and-log-purge-lab.md): Verify syntax, explore `--help`, inspect disk backups with `--list`, and run sandboxed `--err` / `--slow` log rotation.
